Golden dataset

30 fictional PRDs for 6 AI features. Each failure mode has a sound and a flawed version of the relevant passage; every PRD is assembled from those parts, so each label is exact by construction.

How the judge works

The model is the only part that can vary. Everything around it is code, and the same inputs always build the same prompt.

Fixed by code

  • The prompt is compiled from the failure-mode definitions and the PRD. Its fingerprint is shown below.
  • Output must be JSON with all 10 keys and one of pass, fail or na. Anything else is recorded as a schema failure.
  • Every PRD passage the judge quotes is checked word for word against the PRD.
  • If the judge says there is no eval plan (FM01 fails), the eval-plan checks must be na. Violations are counted.
  • Answer caching is off, so 3 runs are 3 real answers.

Measured, not assumed

Current Claude models don't accept a temperature setting, so no judge is exactly repeatable. Instead the page runs each case 3 times and reports how often the runs agree.
